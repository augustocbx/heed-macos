# Live speech language

Settings → Live speech language selects English or Brazilian Portuguese independently of Interface language and Real-time transcription. Changing speech language does not enable preview. The backend saves preferences; an admitted recording retains its effective language, engine family and capture mode. The settings page distinguishes the current live model from the final model and explains changes for the next recording.

On the supported native Mac path, final processing uses Parakeet with the existing English/Portuguese detector, while provisional live text uses the registered multilingual MLX Whisper preview. Selecting Portuguese sends `language:pt, task:transcribe` to both capture channels. There is no live automatic language choice, translation task, vocabulary substitution or advertised mixed-language guarantee. English-only `.en` models reject Portuguese; unknown model identities have no inferred support. Settings and health metadata do not warm a disabled preview.

The existing governor may adapt among compatible models in the admitted family. Status shows the actual runtime model separately from the initial model. A worker restart restores the admitted options before live work. An unavailable live result preserves capture and existing preview; final processing and source correction remain independent.

If the selected path cannot support the saved language, start refuses before capture. “Record final-only (keeps real-time off)” explicitly saves Real-time transcription off and then performs normal admission. This preference remains off for future meetings until changed in Settings. A failed preference write prevents start; a later admission failure still reports that off was saved. Concurrent preference changes between these calls are resolved by the backend at admission. No request or SSE query overrides device preferences.

With preview off, live engine/model/effective language are null and no live ASR, diarization, microphone filtering or warmup is issued. Audio remains available for final processing. Final detected language, timestamps, speaker attribution, diagnostic provenance and corrected accepted source remain authoritative; provisional PT selection never overwrites them.

Registered support is distinct from measured accuracy. The public evaluation cohort contains authored eSpeak NG synthetic speech, short utterances, names, technical vocabulary, alternating EN/PT, concatenated within-turn switching, two-channel overlap and silence. It does not establish human regional accents or natural bilingual quality. Actual two-Mac runs and manual public-prediction review are documented in [the issue 70 QA record](qa/issue-70-live-languages.md). Until those results exist, measured language/mixed capability remains unverified. Broader live segmentation and diarization improvements stay in issue #22.
