# Portuguese Live Speech Language Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. The user approved the recommended design and agent execution; controller assignment starts product work. This commit is docs only, with no further user approval flow.

**Goal:** Deliver real EN/PT live language selection with accurate engine/model capabilities, immutable capture options and measured Portuguese/mixed-language limitations.

**Architecture:** Extend #63's device settings/admission snapshot and existing preview worker/governor lifecycle. Describe actual live and final paths separately, preserve language/engine family throughout capture, and use compatible same-family adaptive models. Unsupported live selection offers explicit persisted final-only recording; final recognition/corrections remain authoritative.

**Tech Stack:** Existing Bun 1.4.2/TypeScript coordinator/config/HTTP, React/Zustand/Vitest, Python MLX/CTranslate2 engines and owned bounded workers, Swift menu. No new product dependency or model downloader.

**Spec:** [Approved bounded specification](../specs/2026-10-06-issue-70-portuguese-live.md).

## Global Constraints

- Product execution integrates reviewed #63 and #7 first; planning base is merged-#63 `298bc324f1b6f7d9764572ca786f57983715de4e`.
- Persist `live_speech_language:'en'|'pt'`, default English for missing/invalid legacy data. Reject invalid new writes.
- Independent of `ui_locale`, #63 real-time preference and existing final EN/PT automatic-detection pipeline.
- Initial choices are English and Brazilian Portuguese. Do not add automatic preview selection in this delivery.
- `task:'transcribe'`, no translation/vocabulary substitution or implicit final-language override.
- Effective language and engine family remain immutable; preserve existing governor adaptation only among compatible same-family models supporting the admitted language.
- Unsupported/unknown live selection with enabled preview returns HTTP 409 before capture and offers explicit persisted-off final-only recording; request overrides are rejected.
- Capability health resolution has a bounded two-second deadline without inference. Disabled preview issues no live ASR/diar/filter/warm-up.
- Preserve #63 counted leases, worker deadline/cancellation/reaping, validated startup owner/generation handshakes, shared final resources and capture priority. No parallel owner/governor/unload framework.
- Keep provisional recognition distinct from accepted final source; preserve #7 corrections/history/version and speaker identity.
- Four interface locales; English source/docs/commits; authored speech language preserved; no author-credit trailers. Synthetic/licensed public evidence only.
- Run at least three actual evaluation repetitions per fixed language/fixture on both Macs. Mixed reliability advertisement requires no silent translation or missed/duplicated annotated language spans and at least 90% annotated EN/PT span-language preservation across those runs; report other quality/latency limitations.

## Review Focus

1. A loaded English-only `.en` or unknown model must not acquire Portuguese capability because final engine supports PT or a library family is multilingual (Task 1).
2. A settings edit during pending admission, duplicate command or Python-only restart must not change an already admitted language/mode; disabled active capture must never warm the next preference (Tasks2–3).
3. Governor degradation/recovery or dead-worker recreation must keep the admitted language/engine family, preserve offsets and report the model actually used, not the next planned model (Task 3).
4. Browser closure/locale change or native start with no browser must use the same persisted selection and explicit final-only choice; late live text must not replace corrected final source (Tasks4–5).
5. Silence/short names/within-turn EN/PT switching can pass transport while translating, omitting or hallucinating words; genuine model/cohort evidence must govern capability claims (Task 6).
