# Label-scoped meeting chat

Approved scope: a general Meeting chat page using the local evidence engine from #16. Default labels combine with any; all is explicit. Empty selected labels remain unready. All meetings is a separate explicit scope. Before sending, show selected labels/rule, matching and eligible counts, unavailable meetings, and inspectable included meeting titles.

The server computes an eligible source snapshot from complete local sessions, filtering labels before reading transcript evidence. Eligible meetings must have a saved final nonempty transcript. The snapshot contains selected labels/rule, meeting IDs/titles/tags and canonical transcript revisions; its hash pins the request. Requests with stale preview hashes fail closed. Each label selection has separate durable history. Each turn stores its immutable source snapshot; only completed turns with the exact same snapshot hash enter follow-up context. No unfiltered summaries, cross-scope caches or prior broader history are used.

Label/membership edits, deletion and transcript revisions mark old turns historical. A queued or running turn whose snapshot changes fails and discards its answer. Supplied evidence IDs remain strict per-chunk allowlists. Citations display the correct meeting and revision and open its segment or text, seeking available audio only after current revision validation. Historical quotes stay readable, with navigation disabled.

Long corpora use the existing bounded chunk scan and show reviewed/total counts, sampling limits and answer truncation. This does not guarantee semantic entailment or contradiction resolution by a real model. Four interface locales remain supported; questions and English/Portuguese sources stay independent of interface language. The worker shares installed local-only transport and resource serialization with notes, tasks and single-meeting chat, yielding before recording/final ASR. Tests use synthetic excluded secret markers and isolated app/recording state; physical Macs and real model quality remain manual acceptance.
