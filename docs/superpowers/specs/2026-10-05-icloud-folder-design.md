# User-selected iCloud folder connector

The user authorized implementation, independent QA corrections and merge after green exact-head CI. This connector follows the SMB milestone and shares the #26/#27 portable identity, immutable revision, reservation and private-cache contracts.

A native macOS 14+ bridge uses a user-selected folder, a device-local security-scoped bookmark, `NSFileCoordinator`, explicit placeholder hydration and asynchronous `NSMetadataQuery` status notifications. The first capability prototype must compile and run only against disposable local fixtures before implementing publication. A missing sign-in token, missing folder, failed authorization, non-ubiquitous folder or unavailable upload attributes is an explicit capability state. No real account/folder is selected by tests.

All imported artifacts are complete and hash-verified before committing a private local session. Only user-requested audio is fetched. Immutable provider writes publish independent commit markers last. Folder disappearance, sign-out and partial listing do not delete private meetings or infer remote deletion. Disconnect releases authorization and retains private imported transcripts.

Upload attributes are read outside coordinated accessor blocks. An ordinary local write/read-back proves only local integrity; iCloud's uploaded flag is a system-reported upload state, not a server checksum receipt. The initial connector reports this distinction and retains pending private copies whenever independent remote verification is unavailable. Two-device round-trip acceptance remains required before asserting remotely verified backup behavior.

The app owns private quota reservations; iCloud hydration/cache files in the selected external folder are OS-managed and excluded. Pending-source references and bounded queue journals survive restart; optional jobs pause when protected data fills the quota. Settings, account identity, authorization and credentials are device-local.

Public API references: [uploaded state](https://developer.apple.com/documentation/foundation/urlresourcekey/ubiquitousitemisuploadedkey), [file coordination](https://developer.apple.com/documentation/foundation/nsfilecoordinator), [folder authorization](https://developer.apple.com/documentation/foundation/url/startaccessingsecurityscopedresource()), [account availability](https://developer.apple.com/documentation/foundation/filemanager/ubiquityidentitytoken), [scoped metadata queries](https://developer.apple.com/documentation/foundation/nsmetadataquery/searchscopes). Current application distribution is a locally signed macOS app; selected-folder access must be tested independently of app-owned ubiquitous-container provisioning. No CloudKit replacement or App Store-only claim is implied.
