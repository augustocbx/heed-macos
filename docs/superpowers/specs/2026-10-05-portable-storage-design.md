# Portable storage foundation (#26)

Approved implementation scope: versioned portable meeting bundles, durable local identities and import/publish state, quota-aware transcript import, preserved concurrent revisions, verified lazy audio, restart-safe legacy media migration, provider-neutral contracts and four-locale library settings. Real providers/accounts and private meetings are excluded from validation.

The local root is `HEED_APP_DIR/library`: `catalog` contains private identities and immutable revisions/markers, `media` content-addressed audio, `indexes` bounded derived data, and `staging` bounded temporary jobs. Existing `SessionTags` session files remain authoritative for all application/AI consumers. Legacy IDs remain local aliases; portable UUIDs never break accepted task/chat links.

Schema v1 uses independent library, meeting, revision and device UUIDs. Revisions include parent IDs. Only explicitly selected finalized meeting fields and optional content-addressed audio references are portable. Credentials, embeddings, runtime paths and live databases are never exported. Required artifact byte counts and SHA-256 hashes are verified before a complete local session write. An immutable device commit marker, referencing the manifest hash, is published last. Integrity is distinct from encryption; providers must declare transport/confirmation capabilities. Local folder writes alone do not prove remote confirmation.

Discovery is paginated and bounded, downloads metadata only and preserves previously observed records on partial listings/outages. Remote-only previews are excluded from local AI. Imports sort by creation time with a stable ID tie-breaker, reserve staged/canonical/session/index allocations, validate and commit complete transcripts, then advance the durable checkpoint. Divergent revisions remain conflict candidates without overwriting local edits. Import retries reconcile existing verified revisions. Optional audio is fetched only on request, hash-verified and quota-reserved; cache removal never deletes remote objects.

Media migration copies verified audio into managed storage before atomically changing local references. The legacy source remains until no session references it. Failure preserves recoverable bounded staging/state. Pending uploads/conflicts/media operations expose protected paths to quota. Imported text is never evicted automatically.
