# Project instructions

All project-facing content in `augustocbx/heed-macos` must be written in English, including source code, comments, documentation, issues, pull requests, review comments, commit messages, and technical logs. This repository-specific instruction overrides the global Portuguese-language preference for `augustocbx` repositories.

Preserve the supported English, Brazilian Portuguese, French, and German interface translations. Locale dictionaries and user-authored meeting content may contain their respective languages; source identifiers and the English fallback remain in English.

Never add `Co-Authored-By` trailers.
